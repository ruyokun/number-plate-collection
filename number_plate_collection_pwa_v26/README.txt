# ナンバープレートコレクション PWA v26

v25をベースに、iPhoneのホーム画面から「ウェブアプリとして開く」ためのPWA構成を追加しました。

追加ファイル:
- manifest.json
- sw.js
- icons/icon-180.png
- icons/icon-192.png
- icons/icon-512.png

維持している機能:
- 北海道→沖縄の8地方区分
- すべて / 未分類 / 収集済み
- 地域検索
- ナンバープレート風のランダム表示
- 収集日と収集日の編集
- ライト / ダークテーマ
- 端末内保存（localStorage）

iPhoneで使う手順:
1. このフォルダをHTTPSで公開する。
2. iPhoneのSafariでサイトを開く。
3. 共有 → 「ホーム画面に追加」。
4. 「ウェブアプリとして開く」をオンにして追加。

オフライン:
- 最初にオンラインで起動してService Workerが登録されれば、キャッシュされたアプリ本体をオフラインで起動できます。
- コレクションデータはv25と同じく端末側に保存されます。

重要:
- PWAのService WorkerはHTTPS（または開発時のlocalhost等）で動作します。
- このZIPをHTTPS対応ホスティングに配置してからiPhone実機でテストしてください。
